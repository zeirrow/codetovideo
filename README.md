
# 🎥 CodeToVideo Documentation

Turn your code into slick, animated videos. Perfect for tutorials, demos, and shipping those "wait, how did you do that?" moments.

---

## 🧠 How It Works

### ✨ Syntax Highlighting

* Powered by [CodeMirror](https://codemirror.net/)
* Full theme support out of the box

### 🎬 Typing Animation

* Character-by-character rendering
* Custom speed & delay per character or globally

### 📦 In-Browser Rendering

* Uses `ffmpeg.js` to generate actual video frames
* No server or external render needed — it's all **client-side**

---

## 🎞 Export Options

* ✅ MP4 (default)
* 🕒 30fps frame rate
* ✂️ Auto-trims leading/trailing idle frames
* 🧪 WebM support (in-progress)
